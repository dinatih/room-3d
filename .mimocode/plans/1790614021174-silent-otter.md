# Plan: Inverser kitchen-s* ↔ kitchen-n* dans PILLAR_DEFS et toutes les références

## Contexte

Dans le système `PILLAR_DEFS`, les piliers `kitchen-sw/se` sont à **z=403.6** (bord côté séjour = côté **nord** de la cuisine) et les `kitchen-nw/ne` sont à **z=463.6** (fond = côté **sud** de la cuisine). Les noms sont donc inversés par rapport à la réalité géographique.

L'objectif est de renommer :
- `kitchen-sw` → `kitchen-nw` (z=403.6, côté nord cuisine)
- `kitchen-se` → `kitchen-ne` (z=403.6, côté nord cuisine)
- `kitchen-nw` → `kitchen-sw` (z=463.6, côté sud cuisine / fond)
- `kitchen-ne` → `kitchen-se` (z=463.6, côté sud cuisine / fond)

## Approche

Étant donné que les paires `sw↔nw` et `se↔ne` sont des swaps, un simple find-replace direct causerait des collisions. Utiliser un placeholder temporaire.

### Étape 1 — Renommer via placeholder temporaire

Dans **tous les fichiers** concernés, effectuer dans l'ordre :

1. `kitchen-sw` → `kitchen-_tmp_sw_`
2. `kitchen-nw` → `kitchen-sw`
3. `kitchen-_tmp_sw_` → `kitchen-nw`
4. `kitchen-se` → `kitchen-_tmp_se_`
5. `kitchen-ne` → `kitchen-se`
6. `kitchen-_tmp_se_` → `kitchen-ne`

Puis aussi :
7. `MEASURED_DIST_KITCHEN_SW_TO_SE` → `MEASURED_DIST_KITCHEN_NW_TO_NE`
8. `kitchen-sw-to-se` (measurement ID) → `kitchen-nw-to-ne`

### Fichiers à modifier

**Total : ~44 remplacements** dans 5 fichiers.

### Étape 2 — Renommer la constante de mesure

Dans `config.ts` :
```diff
- /** Largeur de l'ouverture cuisine entre kitchen-sw et kitchen-se : 102 cm */
- export const MEASURED_DIST_KITCHEN_SW_TO_SE = 102;
+ /** Largeur de l'ouverture cuisine entre kitchen-nw et kitchen-ne : 102 cm */
+ export const MEASURED_DIST_KITCHEN_NW_TO_NE = 102;
```

Dans `RealMeasurementsLayer.tsx` (import + usage) :
```diff
- MEASURED_DIST_KITCHEN_SW_TO_SE,
+ MEASURED_DIST_KITCHEN_NW_TO_NE,
```

```diff
- id: 'kitchen-sw-to-se',
+ id: 'kitchen-nw-to-ne',
```

```diff
- valueCm: MEASURED_DIST_KITCHEN_SW_TO_SE,
+ valueCm: MEASURED_DIST_KITCHEN_NW_TO_NE,
```

### Étape 3 — Corriger les commentaires

`config.ts` ligne 14 :
```diff
- /** Distance Z entre le mur nord de la SDB (Z de bath-nw/kitchen-nw) et shower-ne : 141 cm */
+ /** Distance Z entre le mur nord de la SDB (Z de bath-nw/kitchen-sw) et shower-ne : 141 cm */
```

Note : `bath-nw` reste à z=463.6 (non modifié). Après swap, le pilier à z=463.6 côté ouest s'appelle `kitchen-sw`.

### Étape 4 — Ne PAS modifier

- **`config.ts`** constantes `KITCHEN_X0`, `KITCHEN_X1`, `KITCHEN_DEPTH`, `KITCHEN_Z` — inchangées (valeurs de position, pas des IDs)
- **`KitchenPlacements.tsx`**, **`CuisineGroup.tsx`** — utilisent les constantes directement, pas les IDs de piliers
- **`floorDraw.ts`**, **`Walls.tsx`** — itèrent sur `PILLAR_DEFS` par ID, pas besoin de modification

## Vérification
