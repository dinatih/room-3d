# Références approuvées

Ce dossier accueille uniquement les fichiers créés par une approbation explicite :

```bash
npm run test:perf -- --case=7-mid --approve-reference=machine-7-mid
```

Trois passages complets et compatibles sont exigés. Examiner les rapports avant de versionner la référence. Une campagne ordinaire ne crée aucun fichier ici et aucun objectif de FPS/RAM n’est présumé satisfaisant.
